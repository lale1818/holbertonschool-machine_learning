# Hyperparameter Tuning

This project covers techniques for hyperparameter tuning in machine learning, specifically focusing on Gaussian Processes and Bayesian Optimization.

## Tasks
* **0. Initialize Gaussian Process**: Class initialization and kernel computation.
* **1. Gaussian Process Prediction**: Predicting mean and variance for new data points.
* **2. Update Gaussian Process**: Updating GP with new sample points.
* **3. Bayesian Optimization - Initialize**: Class initialization for Bayesian Optimization.
* **4. Bayesian Optimization - Acquisition**: Implementation of Expected Improvement acquisition function.
* **5. Bayesian Optimization**: Implementation of the full optimization loop.
