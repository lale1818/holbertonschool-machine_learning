# Deep Convolutional Neural Networks

This directory contains implementations of advanced Deep CNN architectures (ResNet, Inception, DenseNet, etc.) built using TensorFlow/Keras.

## Requirements
- Python 3.9
- TensorFlow 2.x
- `pycodestyle` 2.11.1

## Files
- `2-identity_block.py`: Function that builds an identity block for ResNet architectures.
