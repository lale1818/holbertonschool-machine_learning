# Convolutional Neural Networks (CNN)

This directory contains implementations of fundamental Convolutional Neural Network operations built from scratch using NumPy, as well as model architectures built with Keras.

## Requirements
- Python 3.9
- NumPy 1.25.2
- TensorFlow / Keras
- `pycodestyle` 2.11.1

## Files
- `0-conv_forward.py`: Implements forward propagation over a convolutional layer.
- `1-pool_forward.py`: Implements forward propagation over a pooling layer.
- `2-conv_backward.py`: Implements backward propagation over a convolutional layer.
- `3-pool_backward.py`: Implements backward propagation over a pooling layer.
- `5-lenet5.py`: Builds and compiles a modified LeNet-5 CNN model using Keras.
