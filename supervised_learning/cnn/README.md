# Convolutional Neural Networks (CNN)

This directory contains implementations of fundamental Convolutional Neural Network operations built from scratch using NumPy.

## Requirements
- Python 3.9
- NumPy 1.25.2
- `pycodestyle` 2.11.1

## Files
- `0-conv_forward.py`: Implements forward propagation over a convolutional layer with support for padding, strides, and custom activation functions.
