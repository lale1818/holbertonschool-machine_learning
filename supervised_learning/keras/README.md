# Autoencoders

This directory contains projects and tasks related to Autoencoders in unsupervised machine learning using TensorFlow/Keras.

## Learning Objectives
* What is an autoencoder?
* What is latent space?
* What is a bottleneck?
* What is a sparse autoencoder?
* What is a convolutional autoencoder?
* What is a generative model?
* What is a variational autoencoder?
* What is the Kullback-Leibler divergence?

## Tasks
* **0. "Vanilla" Autoencoder**: `0-vanilla.py` - A script that creates a basic vanilla autoencoder.
