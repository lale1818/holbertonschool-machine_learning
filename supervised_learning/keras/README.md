# Reinforcement Learning - Q-Learning

This directory contains tasks for implementing Reinforcement Learning algorithms using Gymnasium's FrozenLake environment.

## Tasks
* **0. Load the Environment**: `0-load_env.py` - Loads the FrozenLake environment from Gymnasium.
* **1. Initialize Q-table**: `1-q_init.py` - Initializes the Q-table with zeros.
* **2. Epsilon Greedy**: `2-epsilon_greedy.py` - Uses epsilon-greedy strategy for action selection.
* **3. Q-learning**: `3-q_learning.py` - Implements the Q-learning algorithm.
* **4. Play**: `4-play.py` - Plays an episode using trained Q-table.
