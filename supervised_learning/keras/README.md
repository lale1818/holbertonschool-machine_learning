# Q-Learning

This project covers the implementation of Reinforcement Learning concepts, specifically Q-learning and Value Iteration using Gymnasium's `FrozenLake-v1` environment.

## Learning Objectives
- What is Reinforcement Learning?
- What is an environment?
- What is an agent?
- What is a state?
- What is an action?
- What is a reward?
- What is a Q-table?
- What is Q-learning?
- What is Epsilon Greedy strategy?

## Tasks
* **0. Load the Environment**: `0-load_env.py` - Loads the FrozenLake environment from Gymnasium.
* **1. Initialize Q-table**: `1-q_init.py` - Initializes the Q-table with zeros.
* **2. Epsilon Greedy**: `2-epsilon_greedy.py` - Uses epsilon-greedy strategy to determine the next action.
* **3. Q-learning**: `3-q_learning.py` - Trains an agent using Q-learning.
* **4. Play**: `4-play.py` - Plays an episode using trained Q-table.
