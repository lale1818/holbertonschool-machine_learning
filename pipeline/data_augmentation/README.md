# Data Augmentation

This directory contains Python scripts for various data augmentation techniques using TensorFlow.

## Requirements
- Python 3.9
- TensorFlow 2.x
- `pycodestyle` 2.11.1

## Files
- `0-flip.py`: Function that flips a 3D image tensor horizontally.
- `1-crop.py`: Function that performs a random crop of a 3D image tensor.
- `2-rotate.py`: Function that rotates a 3D image tensor by 90 degrees counter-clockwise.
- `3-contrast.py`: Function that randomly adjusts the contrast of a 3D image tensor.
- `4-brightness.py`: Function that randomly adjusts the brightness of a 3D image tensor.
- `5-hue.py`: Function that adjusts the hue of a 3D image tensor by a specified delta.
