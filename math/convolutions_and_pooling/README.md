# Math - Convolutions and Pooling

This directory contains tasks and exercises related to image convolutions and pooling operations in deep learning, including:
- Valid Convolution on Grayscale Images
- Same Convolution on Grayscale Images
- Convolution with Custom Padding
- Strided Convolution
- Convolution on Channels / Color Images
- Pooling Operations (Max and Average Pooling)
