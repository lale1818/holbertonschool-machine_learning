# Math - Probability

This project covers the implementation of various probability distributions in Python without using external libraries like `math` or `numpy`.

## Distributions Included:

### 1. Poisson Distribution
- Initialize with data or lambtha.
- Calculate **PMF** (Probability Mass Function).
- Calculate **CDF** (Cumulative Distribution Function).

### 2. Exponential Distribution
- Initialize with data or lambtha.
- Calculate **PDF** (Probability Density Function).
- Calculate **CDF** (Cumulative Distribution Function).

### 3. Normal Distribution
- Initialize with data, mean, and standard deviation.
- Calculate **Z-score** and **X-value**.
- Calculate **PDF** (Probability Density Function).
- Calculate **CDF** (Cumulative Distribution Function) using an approximation of the error function.

### 4. Binomial Distribution
- Initialize with data, n (number of trials), and p (probability of success).
- Calculate **PMF** (Probability Mass Function).
- Calculate **CDF** (Cumulative Distribution Function).

## Requirements
- All files are interpreted on Ubuntu 16.04 LTS using `python3` (version 3.5).
- All files conform to the `pycodestyle` style (version 2.5).
- All modules and classes have documentation.
